# UX and Content Specification

## Principles
Show estimates and uncertainty, expose sources/dates, avoid spending-inducing dark patterns, never imply guaranteed rewards, distinguish zero/missing/unknown/stale/conflicting.

## Preferred copy
- “Estimated reward value.”
- “Based on terms verified as of [date].”
- “Assumes the cap has not already been used.”
- “We could not verify this from available official sources.”
- “Point value is your selected assumption.”

Avoid “guaranteed cashback,” “you will definitely earn,” and unqualified “best card.”

## Screens
Dashboard, catalogue/card detail, portfolio, scenario editor, comparison, optimizer, assistant, reminders, settings/privacy, admin review queue.

## Comparison
Show gross reward, cap, exclusions, fee method, point valuation, verification status, source dates, and trace.

## Accessibility
Keyboard support, semantic headings/labels/table headers, focus indicators, non-color status cues, responsive layout, clear errors, accessible currency, designed loading/empty/stale/offline states.
