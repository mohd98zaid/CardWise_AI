# Frontend Specification

## Navigation
Dashboard, My Cards, Catalogue, Scenarios, Compare, Optimizer, Benefits/Reminders, Terms Assistant, Settings/Privacy, role-gated Admin.

## Dashboard
Portfolio size, latest scenario, estimated reward value, potential improvement, reminders, stale/uncertain rule notices. Avoid guaranteed-savings claims.

## Catalogue/card detail
Exact variant, verification status, source dates, fees, rates, caps, exclusions, thresholds, benefits, source links, history, add-to-portfolio action.

## Scenario editor
Category/channel rows, currency/date, optional transaction counts, allocations, cap-use assumptions, unknown indicators, save/duplicate/delete.

## Compare
Side-by-side results, gross and net estimates, cap utilization, exclusions, fee treatment, point valuation, verification state, trace, official evidence.

## Optimizer
Baseline/proposal, incremental value, per-card/category breakdown, constraint state, cap/threshold effects, sensitivity, save as new scenario.

## Assistant
Card context, cited evidence and dates, abstention state, report-answer action, clear separation from calculator output.

## Accessibility
Keyboard navigation, semantic labels/headings/table headers, focus indicators, non-color status cues, responsive layout, helpful errors, accessible currency values, and designed loading/empty/stale/offline states.
