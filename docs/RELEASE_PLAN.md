# Release Plan

## Alpha
Synthetic cards only, internal users, catalogue/rules/scenarios/calculator/traces. No claims about current issuer terms.

## Private beta
Small independently verified card set, invited users, discrepancy reporting. AI remains disabled or explicitly experimental until evaluation passes.

## Public MVP gates
Verified launch catalogue; calculation suite passes; authorization/security review; export/deletion and retention policy; source rights review; backup restore tested; monitoring/runbooks; clear estimate disclosures; no critical/high unresolved defects.

## Version 1
Evaluated RAG assistant, stale-source detection, more variants, optional CSV summaries, opt-in notifications.

## Rollback triggers
Critical calculation discrepancy, unauthorized data access, material rule published without evidence, migration corruption, severe unsupported-claim regression. Preserve historical manifests and audit records.
