# Architecture Decision Records

Create one Markdown file per material decision.

```markdown
# ADR-NNN: Title
- Status: proposed | accepted | superseded
- Date:
- Owner:

## Context
## Options
## Decision
## Consequences
## Revisit conditions
```

Initial ADRs: modular monolith, PostgreSQL, Decimal + manifests, evidence/review gates, full-text before vector search, no issuer credential collection.
