# Security Policy

Before public launch, configure a private security-reporting contact. Do not ask reporters to publish exploitable details.

Scope includes authentication/authorization, user data isolation, rule administration, source ingestion and prompt injection, secrets/deployment, export/deletion.

Response: acknowledge, assess severity, contain, preserve evidence, patch/test, coordinate disclosure, document corrective actions.

Never include real card numbers, CVV, PIN, OTP, passwords, tokens, or private spending records in reports or test fixtures.
